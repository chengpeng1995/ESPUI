## 文档结构

八个独立章节：如何使用、基础与圆屏布局、组件规范、表单规范、页面规范、弹窗与覆盖层、动效与手势、实现与验收。

- 10 组独立组件：按钮、开关、滑块、列表行、输入框、分段选择、步进器、数字滚轮、状态反馈、图标按钮。
- 3 个完整表单流程：密码、日期时间、闹钟；包含校验、草稿、取消确认、保存与失败反馈。
- 六应用与首页、应用入口、最近任务的交互样机，设置九个入口和完整子页目录。
- 6 种覆盖层：未保存、危险确认、选择、轻提示、到点提醒、快捷面板。
- 动效实验区：图标跟手缩放、吸附、任务上滑关闭与取消回弹；支持暂停、重播、慢速观察与减少动态效果。

所有展示使用 HTML 元素、CSS 与内联 SVG 图标。无 `img`、SVG `image`、Canvas、内嵌图片或远程资源。文件约 203 KB，替代上一版约 3.15 MB 的截图图鉴。

## 底部几何

- 列表视口：x=81、y=110、宽 304、高 344，延伸至 y=454。
- 44 px 列表内部尾距用于末项停靠：末项底边 y=410，避开物理圆角。不是悬浮遮罩。
- 横条：64×4，位于 (201,452)，不接收指针事件。
- 底部手势只在 (191,448) 的 84×16 区域起手。内容区不被全宽透明按钮接管。
- 非滚动的圆屏外壳使用 `overflow: clip`；只有真实列表容器滚动。

此几何是设计目标，尚未在真机验证触控成功率与误触率。

## 维护与实现边界

单文件可直接编辑。若从本轮拆分源重新生成，在项目根目录执行：

```sh
python3 .runtime/spec-v2/build.py
```

`build.py` 将材料变量、图标定义、文档内容、组件交互和页面样机组合为一个 HTML。材料 CSS 与第一组 SVG defs 保留 `assets/blue_ui/generate_assets.py` 所需的读取契约；本轮没有重新生成固件资产。

页面交互只修改当前文档的内存状态，不连接网络、设备、真实账户、麦克风或系统闹钟。语言选择是本地选值示例；英文排版以独立长文案组件展示，不宣称整个样机已完成英文翻译。

当前固件为 Blue 2.6.0。浏览器和固件分别验证，不能用浏览器流畅度推断设备性能；约 29.4 FPS 的历史结果与本轮按场景记录的实测须按日志区分。`patch_app.py` 是旧版迁移脚本，不能再次运行覆盖已经更新的 app.js。

## 弹窗边缘修正（2026-10-10）

修复背景主按钮下沿外露形成“第二层边框”的视觉问题：阻塞弹窗后方整页统一模糊 8 px 并压暗；玻璃表面统一使用 1 px 低对比描边、轻顶部内高光，删除底部亮边。所有内容与反光按同一圆角裁切。

未保存、危险确认、选择、提醒、快捷面板以及表单确认共享边缘变量；轻提示仍不模糊整页。桌面和 390 px 窄屏已检查，弹层尺寸无变化、内容无溢出、脚本无异常。预览 `docs/spec-v2-popup-border-fixed.png` 仅为验证截图，不嵌入规范 HTML。

## 底部上滑语义修正（2026-10-10）

底部短上滑现在表示退出当前应用并返回应用列表，同时移除最近任务中的当前应用项。退出设置子页时关闭的是所属应用。退出不再显示首页；未保存表单先确认，取消时保留原草稿，确认放弃后完成退出。计时与闹钟服务不因界面退出而停止。

上滑后停留进入最近任务、底部横滑切换及未达阈值取消保留。辅助导航和文档操作按钮同步改为“退出应用”。首页仍可以通过文档的页面选择器单独查看。

21 项专项浏览器检查通过：六应用退出、任务移除、子页草稿保护、计时继续、长停留最近任务、辅助导航、窄屏、旧说明清理与脚本错误检查。此修正只更新 HTML 规范与交互样机，Blue 2.2.0 固件手势尚未修改。
