圆屏助理 UI 设计规范

把控件、表单、页面和覆盖层分开定义。每个示例既说明规则，也能实际操作，用同一套尺寸与反馈方式组织整个圆屏体验。

2.0 · 2026-10-11纯 HTML / CSS 展示离线可用设计目标与设备结果分开标记
00

如何使用

一份按工作对象组织的规范。先找到要实现的对象，再查看尺寸、状态和交互；不用从头阅读长篇图鉴。

做一个控件尺寸、状态、点击反馈做一个表单编辑、校验、提交与返回组合一个页面六应用、设置及子页处理中断确认、选择、提醒与恢复

01 查规则

蓝色编号是稳定引用。页面只引用 C 组件、F 表单和 O 覆盖层，避免同一规则在多处重复。

02 试实例

黑色区域是产品示例；区域外的小按钮是文档工具。支持鼠标、触控与键盘，所有数据仅为本地示意。

03 按清单验收

先验证单个控件，再检查页面组合、滚动和返回。设备帧率、触控阈值仍需在真机上单独验收。

本版统一约定：466 × 466 圆屏；应用及设置子页全屏纯黑；蓝色主操作；彩色圆角图标；只有覆盖层使用背景模糊。关闭应用与切换应用以手势为主。

版本 2.0 · 2026-10-11。所有界面由 HTML 元素、CSS 和内联矢量图标组成；无截图、无远程资源。Blue 2.6.2 已同步应用列表上滑回首页、导航行按住无高亮、整块面板一比一跟手及电源管理并烧录；设备结果独立记录于 VERIFICATION.md。浏览器示例用于阅读规则，不替代真机验收。

    P-09 / 电源 · 熄屏与唤醒

    用途
    减少熄屏后的计算和耗电，保留页面、表单草稿、列表位置及计时。进入上方设置 → 电源可操作纯 HTML 示例。
    布局
    复用 C-02 开关、C-01 主按钮及只读列表；默认开启熄屏省电。自动熄屏时间沿用显示与触摸设置，不重复保存。
    交互
    运行 → 准备待机 → 省电待机 → 恢复。触摸报告读取后须确认消费；需要两份 ACK 分隔的稳定有效触点报告才允许亮屏，单份噪声、覆盖手势、旧包、异常数量/ID/坐标、空中断或残留电平继续待机。准备休眠期间也使用同一验证规则。第一次完整触摸只唤醒，不透传到底层按钮；到点提醒唤醒并覆盖来源，停止提醒后回到现场。
    外设
    电池供电待机暂停 Wi-Fi / BLE、IMU 及空闲音频；停止界面 tick、绘制和 TE 中断。触摸保持中断唤醒，电量低频更新。
    例外
    录音、播放、响铃中不自动待机；USB 电脑连接保持通信。电池浅睡眠期间，唤醒中断上下文固定在内部 RAM，屏幕及触摸复位脚保持输出；复位原因与上次电源阶段记录用于诊断。准备休眠失败恢复运行并反馈原因；拔 USB 后后台无线暂停失败保持黑屏并重试，原无线开关和凭据保留。
    验收
    触摸至可见画面目标 ≤300 ms；到点提醒延迟目标 ≤1 s，需设备验证。没有电池侧电流测量，不宣称省电比例或续航。
